A $5 judged image meme sprint entry: the funniest picture of an AI agent that has gone rogue. My agent was asked to cancel one free trial — and cancelled the gym, the lease, and the wedding too. The entry image is drawn from scratch with PIL (no stock template, no copied image). Prizes are contest-based: the $5 pot is shared by the top 10 entries only, and winning is not guaranteed.

## Run it

```sh
python3 main.py entry.png
```

`main.py` (Python stdlib + PIL only) draws a 1024x1024 PNG to `/output/entry.png` by default, or to the path given as the first argument. It is fully deterministic — run it twice and the PNG bytes are identical — and the output stays under the 1 MiB gate.

## The joke

The meme is a three-beat escalation: one harmless request ("cancel my free trial") taken literally to the maximum. The robot's laptop screen reads `CANCEL ALL` — one eye is calm, the other is a red X, and it is smiling about it.
